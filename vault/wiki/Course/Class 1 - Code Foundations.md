# Class 1 - Code Foundations

Class 1, Code & Programming Foundations, focuses on prototyping with AI to build internal tools, A/B tests, and dashboards rather than becoming a software developer. The class aims to equip students with the ability to read, explain, modify, and test small programs, using the mental model that a program is a precise recipe transforming inputs into outputs.

## Key details

- The goal of the class is to prototype with AI for things like internal tools, A/B tests, and dashboards ([Class 1 slides (Code & Programming Foundations), slide 6: The Goal of This Class](https://haas-ai-classes-fall-26.vercel.app/class1.html#/the-goal-of-this-class)).
- Success in the class means being able to read a small program without panic, explain its inputs, changes, and returns, change one behavior deliberately, test the change, and run a website on one's own machine ([Class 1 slides (Code & Programming Foundations), slide 7: What Success Looks Like Today](https://haas-ai-classes-fall-26.vercel.app/class1.html#/what-success-looks-like-today)).
- A program is conceptualized as a precise recipe that transforms inputs into outputs, while other elements like websites and models are elaborations of that recipe ([Class 1 slides (Code & Programming Foundations), slide 7: What Success Looks Like Today](https://haas-ai-classes-fall-26.vercel.app/class1.html#/what-success-looks-like-today)).
- Key building blocks of all software, from Instagram to self-driving cars, are variables, conditionals, loops, and functions, with complexity arising from combining them ([Class 1 slides (Code & Programming Foundations), slide 36: Key Takeaway](https://haas-ai-classes-fall-26.vercel.app/class1.html#/key-takeaway)).
- The agenda includes topics such as what code is (recipes, binary), building blocks (variables, conditionals, loops, functions), errors as information, programming languages (why Python), the terminal, clean code, Git & GitHub, localhost, and tools like Claude Code, Codex, and YOLO mode ([Class 1 slides (Code & Programming Foundations), slide 8: Today’s Agenda](https://haas-ai-classes-fall-26.vercel.app/class1.html#/todays-agenda)).
- The exercise involves building a business-rule engine, the discount-engine, which must run on the machine, be viewable in a browser, and be structured logically ([Class 1 slides (Code & Programming Foundations), slide 122: The Brief](https://haas-ai-classes-fall-26.vercel.app/class1.html#/the-brief)).
- The definition of done for the discount-engine includes having a README, sensible structure, running on localhost in a browser, passing unit tests for rules, using plan mode, and pushing to GitHub with readable commit messages ([Class 1 slides (Code & Programming Foundations), slide 124: Definition of Done](https://haas-ai-classes-fall-26.vercel.app/class1.html#/definition-of-done)).

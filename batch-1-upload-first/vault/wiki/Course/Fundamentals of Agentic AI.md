# Fundamentals of Agentic AI

Fundamentals of Agentic AI is a seven-class course; this wiki covers the first five, which move from code and programming through software systems, machine learning, and deep learning to LLM behavior, prompting, and retrieval. Each class ends in a hands-on assignment that I documented in my own repository.

## Key details

- Class 1: Code & Programming Foundations covers topics such as what code is, building blocks like variables and loops, programming languages (specifically Python), and tools like Claude Code and Codex ([Class 1 slides (Code & Programming Foundations), slide 8: Today’s Agenda](https://haas-ai-classes-fall-26.vercel.app/class1.html#/todays-agenda)).
- Class 2: Software Systems — Frontend to Deployment covers topics including Frontend (HTML, CSS, JavaScript), Backend (servers, APIs), Databases (SQL), and deployment to a live URL, with Assignment 1 being building and deploying a networking tracker ([Class 2 slides (Software Systems), slide 6: Today’s Agenda](https://haas-ai-classes-fall-26.vercel.app/class2.html#/todays-agenda)).
- Class 3: Machine Learning Foundations covers concepts like AI history, defining predictions, fitting models by reducing loss, training digit classifiers in Colab, and reinforcement learning (e.g., Pac-Man) ([Class 3 slides (Machine Learning Foundations), slide 16: Today’s Route](https://haas-ai-classes-fall-26.vercel.app/class3.html#/todays-route)).
- Class 4: Deep Learning, Embeddings & Transformers covers topics such as one neuron structure, network training (predict, measure loss, calculate gradients, update), and language concepts like tokens, embeddings, and attention ([Class 4 slides (Deep Learning, Embeddings & Transformers), slide 7: Today’s Roadmap](https://haas-ai-classes-fall-26.vercel.app/class4.html#/todays-roadmap)).
- Class 5: LLM Behavior, Prompting & Retrieval covers topics including prompting techniques, context management, fine-tuning, RLHF, Retrieval Augmented Generation (RAG), and Assignment 4, which is building a Personal Wiki CLI around local Gemma + RAG ([Class 5 slides (LLM Behavior, Prompting & Retrieval), slide 5: What This Class Gives You](https://haas-ai-classes-fall-26.vercel.app/class5.html#/what-this-class-gives-you)).
